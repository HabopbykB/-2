# Лабораторная работа №2 — вариант 2

Тема: обучение без учителя, понижение размерности и кластеризация.

Работа состоит из двух частей: анализ признаков методами PCA, SVD и ICA, затем сравнение алгоритмов кластеризации и поиск возможных выбросов.

## Файлы проекта

```text
lab2_variant2.py
Lab2_Dataset_PCA.xlsx
Lab2_Dataset_Clustering.xlsx
README.md
output/
```

В `output` находятся графики в формате PNG. Таблицы с метриками и значения важности компонент выводятся в терминал при запуске, как в образце для варианта 4.

## Установка

Нужен Python 3.10 или новее. Установить библиотеки:

```bash
pip install numpy pandas matplotlib scipy scikit-learn openpyxl
```

Если используется старая версия `scikit-learn`, в которой нет `HDBSCAN`, дополнительно установить:

```bash
pip install hdbscan
```

## Запуск

1. Поместить оба Excel-файла рядом с `lab2_variant2.py`.
2. Открыть проект в PyCharm.
3. Запустить `lab2_variant2.py` или выполнить в терминале:

```bash
python lab2_variant2.py
```

После выполнения в папке `output` появятся графики:

- `01_correlation.png` — корреляции признаков;
- `02_scatter_matrix.png` — матрица разброса;
- `03_pca_importance.png`, `04_svd_importance.png`, `05_ica_importance.png` — значимость компонент;
- `06_pca_projection.png`, `07_svd_projection.png`, `08_ica_projection.png` — двумерные проекции;
- `09_all_algorithms.png` — сравнение 12 алгоритмов кластеризации;
- `10_density_methods.png` — DBSCAN, HDBSCAN и OPTICS;
- `11_anomalies.png` — точки, отнесённые DBSCAN к шуму;
- `12_gmm_reference.png` — сравнение GMM с эталонной разметкой.

## Используемые данные

Для PCA используются столбцы G:L из `Lab2_Dataset_PCA.xlsx` (признаки `a`–`e` и метки `y`). Для кластеризации — D:F из `Lab2_Dataset_Clustering.xlsx` (признаки `a`, `b` и метки `y`). Пустые строки пропускаются.

Признаки перед анализом стандартизируются. Метки `y` не участвуют в обучении моделей: они нужны только для окраски графиков и сравнения кластеризации с правильной разметкой.

## Краткие результаты

В PCA-данных варианта 2 обнаружена точная линейная зависимость признака `e` от `a` и `d`: `e ≈ -0.303609*a + 1.366198*d`. Поэтому ранг матрицы равен 4, а пятая PCA/SVD-компонента практически не несёт дисперсии. PC1 объясняет около 45.68% дисперсии, первые две компоненты — около 66.55%, первые четыре — 100%.

В кластеризации лучшее совпадение с эталонными метками показала смесь гауссовых распределений (`Gaussian Mixture`): ARI около 0.488. Плотностные методы DBSCAN и HDBSCAN хорошо выделяют разреженные точки как шум и подходят для анализа выбросов.
